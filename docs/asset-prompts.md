# Ostra Studio: image and video prompts

Each prompt is complete, so copy one into the generator as it is. Save each result under the file name shown and send the PNGs at 2000 px wide or more.

**Negative prompt for every colour photo (A, B, C, E1, F):**
`people, faces, text, signage, watermark, logos, cars, clutter, multiple orange objects, oversaturated colour, HDR halos, CGI look, plastic surfaces, fisheye distortion, leaning verticals`

**Negative prompt for every black-and-white image (D, E2):**
`colour on the objects, orange tint or spill on the objects, sepia, gradient backdrop, busy background, text, watermark, logos, extra fingers, distorted hands`
